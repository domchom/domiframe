Virtual frame

A frame in a browser tab, for trying DomiFrame without the hardware. It behaves like the firmware: on setup it makes its own frame code and shows it on the screen, sends the device key, battery and ETag, opens the sealed picture with its code, redraws only on a new picture, and sleeps as long as the server says. The device key and code stay in this browser.
