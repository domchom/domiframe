Help and support

Help with frames, the website and the app. If something here doesn't answer it, open an issue at github.com/domchom/domiframe/issues.

Opening your frame

You need the frame's ID and its code. Both are on the frame's screen after setup, with a QR code that opens the frame straight away. To show them again, hold KEY1 on the frame while pressing reset (this works even if the frame can't reach Wi-Fi). On this site, choose My frame and enter them; in the app, tap + and enter them, paste an invite link, or scan an invite QR code.

The frame hasn't changed yet

Frames sleep between check-ins to save battery, so new pictures and changes appear at the next check-in (shown as "Next check-in"). To see them now, press the button on the frame (KEY1): it wakes, checks in, and redraws in about 20 seconds. If it still hasn't changed, check the battery and the Wi-Fi where the frame hangs.

The picture looks different on the frame

The frame has six inks, and every other color is made of dots of them (dithering). That's done when you send, and a phone or computer screen can't show it the way e-paper does, so the preview isn't dithered. Colors on the frame also change with the light in the room and the angle you look from. Try another look, or another dithering style under Detail, and edit the picture again.

Someone shouldn't have the code any more

Make a new frame code: hold KEY3 while pressing reset to open the setup portal, and tick Make a new frame code. The old code and links stop working, and the frame's pictures and folders are deleted (they were locked with the old code). Then share the new code with the people you want.

New Wi-Fi

Hold KEY3 while pressing reset, join the DomiFrame-Setup Wi-Fi from your phone with the password on the frame's screen, and pick the new network.

Asking for help

Open an issue at github.com/domchom/domiframe/issues and say what you see, which screen size the frame is, and whether you use the website or the app. Include the frame's ID if it helps, but never post a frame code: issues are public.
