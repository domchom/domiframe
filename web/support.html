Help and support

Help with frames, the website and the app. New frame? Start with setting it up. If something here doesn't answer it, open an issue at github.com/domchom/domiframe/issues.

Setting up a frame

  1. Switch the frame on. A new frame, or one that can't find its Wi-Fi (because it has moved or was a gift), opens Wi-Fi setup by itself: the screen says Set up Wi-Fi and shows a QR code.
  2. Scan the QR code with your phone's camera and tap to join the frame's Wi-Fi. Or join the DomiFrame-Setup Wi-Fi by hand, with the password on the screen. The setup page opens by itself; if it doesn't, go to 192.168.4.1 in a browser.
  3. Pick your home Wi-Fi, type its password, choose how the frame hangs, and press Connect. A brand-new frame also asks for the frame ID and device key you were given. The page tells you when it's connected, or if the password didn't work.
  4. A new frame then shows its frame code with the frame ID and a QR code. Scan the QR code, or enter the ID and code under My frame here or in the app. The first time it's opened, it gets three famous paintings in a Default folder, so it isn't blank. Send your own pictures, and remove those whenever you like.

Setup waits 10 minutes for you. If the screen says Not on Wi-Fi yet, switch the frame off and on again to start over. Frames only use 2.4 GHz Wi-Fi, so a 5 GHz-only network won't be in the list. If it says Frame not registered, the frame ID or device key is wrong: hold KEY3 and press reset to enter them again.

The frame's buttons

  • KEY1: wakes the frame to check for new pictures now. It redraws in about 20 seconds. If it can't reach its Wi-Fi, it opens Wi-Fi setup.
  • Reset: restarts the frame. It connects, checks for new pictures, and goes back to sleep. If it can't reach its Wi-Fi, it opens Wi-Fi setup.
  • Hold KEY1 and press reset: shows the frame code, frame ID and QR code again. This works even if the frame can't reach Wi-Fi.
  • Hold KEY3 and press reset: opens Wi-Fi setup even when the frame can reach its Wi-Fi, for a new device key, a new frame code, or to turn the frame. Those are under Frame details on the setup page. Leave the device key blank to keep it, and leave Make a new frame code unticked unless you want to shut out everyone who has the code. If the frame lost its code, type the old one into Frame code to get its pictures back.

Keep holding KEY1 or KEY3 for a second after letting go of reset.

The iPhone app

The DomiFrame app for iPhone and iPad does everything this site does, and can also send photos from the share sheet, tell you when a frame is late or its battery is low, and show your frames in widgets. Get it on the App Store. Frames you open in the app and on this site are separate: open the frame in each (with the same ID and code, or its invite link).

Opening your frame

You need the frame's ID and its code. Both are on the frame's screen after setup, with a QR code that opens the frame. To show them again, hold KEY1 on the frame while pressing reset (this works even if the frame can't reach Wi-Fi). On this site, choose My frame and enter them; in the app, tap + and enter them, paste an invite link, or scan an invite QR code.

The frame hasn't changed yet

Frames sleep between check-ins to save battery, so new pictures and changes appear at the next check-in (shown as "Next check-in"). To see them now, press the button on the frame (KEY1): it wakes, checks in, and redraws in about 20 seconds. If it still hasn't changed, check the battery and the Wi-Fi where the frame hangs.

A frame keeps its picture even when its battery is empty, so a low battery shows on its page here, not on the frame. When it's all but empty the frame stops checking in until it's charged with a USB-C cable. It checks its battery every few hours, so it starts again on its own; press KEY1 while it charges to start straight away.

The picture looks different on the frame

The frame has six inks, and other colors are made from dots of them (dithering). That's done when you send, and a phone or computer screen can't show it the way e-paper does, so the preview isn't dithered. Colors on the frame also change with the light in the room and the angle you look from. Try another look, or another dithering style under Detail, and edit the picture again.

Someone shouldn't have the code any more

Make a new frame code: hold KEY3 while pressing reset to open Wi-Fi setup, open Frame details and tick Make a new frame code. The old code and links stop working, and the frame's pictures and folders are put away (they were locked with the old code). Then share the new code with the people you want.

Getting pictures back after a new code

If the frame made a new code by mistake, or lost its code (for example after being wiped), its pictures are kept for 30 days. Find the old code where you opened the frame before (the app or this site keep it), hold KEY3 while pressing reset, and type it into Frame code under Frame details on the setup page. The frame goes back to that code and its pictures come back.

Updates

Frames update themselves over Wi-Fi when new firmware is out, at a check-in, when the battery has enough charge. The picture stays on the screen, and the frame's settings, code and pictures stay as they are.

New Wi-Fi, or a new home

Switch the frame off and on again where it now is. When it can't find its old Wi-Fi it opens Wi-Fi setup by itself, as when it was new: scan the QR code on its screen and pick the new network. Its pictures, settings and code stay as they are. If the old network is still in reach (a new router at the same address, say), hold KEY3 while pressing reset to open setup anyway.

Away from home, a frame that can't reach Wi-Fi keeps its picture up and tries again later, less often each time, so it doesn't run down its battery.

Giving a frame as a present

  1. Set it up on your own Wi-Fi and open its page here or in the app. It gets three paintings in a Default folder, so it isn't blank. Send any pictures you'd like waiting for them too.
  2. Switch it off before you wrap it. It keeps whatever is on its screen, so that's what they see when they open it.
  3. They switch it on at home. It can't find your Wi-Fi, so it opens setup: they scan the QR code, pick their Wi-Fi, and your pictures show up within a minute or so.
  4. Give them the frame's invite link (or the code) so they can send pictures too.

Everyone with the code can see the frame's pictures, you included. For a frame only they can see, they can make a new frame code in its Wi-Fi setup (under Frame details), but the pictures sent before are put away with the old code: it starts again with just the three paintings.

Asking for help

Open an issue at github.com/domchom/domiframe/issues and say what you see, which screen size the frame is, and whether you use the website or the app. Include the frame's ID if it helps, but never post a frame code: issues are public.
